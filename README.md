AI Student Understanding Verification System

An AI-powered Multimodal Student Understanding Verification System that evaluates a student's conceptual understanding by analyzing their spoken explanation through video and audio. The system integrates speech recognition, natural language processing, computer vision, and multimodal AI to generate an explainable understanding report.

Features
🎤 Speech-to-Text using Whisper
🧠 AI-generated reference answers using Qwen 3
📖 Semantic Similarity Analysis
✅ Concept Detection and Concept Coverage
🔍 Knowledge Gap Detection
⚠️ Misconception Detection
👀 Attention Analysis using MediaPipe
😊 Emotion Analysis using DeepFace
⏸️ Speech Confidence Analysis using Long Pause Detection
📊 AUVA (Adaptive Understanding Verification Algorithm)
📝 Explainable AI Verification Report
🌐 Interactive Streamlit Web Application
